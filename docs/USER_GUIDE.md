# Инструкция по работе с платформой Industry Skills

## Вход и язык

1. Откройте платформу и войдите под своей учетной записью.
2. Язык интерфейса переключается в верхней панели. Для англоязычных пользователей используйте английскую версию интерфейса.

## Регистрация участника или эксперта на мероприятие

1. Перейдите в раздел **Мероприятия**.
2. Откройте нужный чемпионат.
3. Выберите роль: участник или эксперт.
4. Ознакомьтесь с предупреждением о снятии заявки, дисквалификации и невозврате регистрационного взноса.
5. Подтвердите согласие с регламентом и отправьте заявку.

## Профиль пользователя

1. Перейдите в раздел **Профиль**.
2. Заполните обязательные поля.
3. Для организации начните вводить название и выберите подходящий вариант из списка. Если организации нет в списке, оставьте введенное название.
4. Загрузите фото профиля с учетом требований на странице.
5. Сохраните изменения.

## Работа участника во время чемпионата

1. Откройте карточку мероприятия.
2. В блоке **Загрузка работ по модулям** загрузите файл для нужного модуля.
3. Если файл по модулю уже был загружен, новая загрузка заменит предыдущую.
4. Загрузка конкурсных файлов доступна только участникам во время статусов **В процессе** или **Оценивание**.

## Фотоотчет команды

1. Откройте карточку мероприятия.
2. В блоке **Фотоотчет команды** нажмите **Добавить фото**.
3. Поддерживаются JPEG, PNG и WebP.
4. Фотоотчет доступен во время чемпионата и после публикации результатов.

## Обратная связь после чемпионата

1. После публикации результатов откройте карточку мероприятия.
2. Заполните форму обратной связи.
3. Отзыв можно обновить повторной отправкой формы.

## Работа эксперта

1. Эксперт видит раздел **Оценивание**.
2. В этом разделе можно выбрать мероприятие и команду, открыть модули и просмотреть критерии оценивания.
3. Эксперту недоступна загрузка конкурсных заданий за команду.
4. В разделе **Паспорта** эксперт может просмотреть и скачать skill passports по мероприятиям, где он подтвержден как эксперт.

## Работа администратора с мероприятиями

1. В разделе **Мероприятия** создайте или откройте чемпионат.
2. Заполните название, компетенцию, даты, описание и статус.
3. Загрузите схему оценки из Excel.
4. При необходимости загрузите фон skill passport.
5. После завершения оценивания подготовьте паспорта и опубликуйте результаты.

## Команды

1. В карточке мероприятия откройте **Управление командами**.
2. Команды можно создать вручную или сформировать автоматически по организациям.
3. Участники и эксперты добавляются из подтвержденных заявок.
4. Эксперт отображается в составе команды отдельной плашкой.

## Работы команд и OBS

1. Откройте **Работы команд**.
2. Выберите мероприятие.
3. Несданные модули подсвечиваются отдельно.
4. Для учета записей экранов отметьте чекбокс **OBS сдан мне** у нужной команды.
5. Для скачивания всех работ нажмите **Подготовить ZIP**, затем скачайте готовый архив.

## Пользователи и организации

1. В разделе **Пользователи** можно искать пользователей, фильтровать по роли и отдельно показать пользователей без фото.
2. Карточка пользователя открывается по имени. В ней можно заменить фото и отредактировать основные данные без возврата в общий список.
3. В разделе **Организации** можно добавлять организации, задавать тип, фильтровать по типу и сливать дубли.

## Паспорта

1. Администратор открывает раздел **Паспорта**.
2. Выберите мероприятие.
3. Скачайте нужный skill passport в PDF.
4. Эксперты видят паспорта только по мероприятиям, где они подтверждены как эксперты.

## Что делать при ошибках

1. Обновите страницу.
2. Проверьте, что выбран правильный язык интерфейса.
3. Проверьте статус мероприятия: часть действий доступна только в определенных статусах.
4. Если проблема повторяется, передайте администратору страницу, действие, роль пользователя и текст ошибки.
