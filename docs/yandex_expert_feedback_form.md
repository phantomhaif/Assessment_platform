# Yandex Forms: обратная связь экспертов по чемпионату Digital Skills 2026

## Название формы

Обратная связь экспертов: Международный Чемпионат Digital Skills 2026

## Описание формы

Анкета для экспертов по итогам Международного Чемпионата Digital Skills, проходившего 15-19 июня 2026 года. Форма общая для всех компетенций и помогает собрать обратную связь по работе платформы оценивания, процессу чемпионата, документам, коммуникации и публикации результатов.

Ответы можно оставить анонимно: ФИО и контакты заполняются только при желании получить обратную связь от организаторов.

## Настройки

- Тип формы: опрос.
- Доступ: по ссылке.
- Сбор email: выключить, если нужна анонимность; включить только если организаторам нужен список ответивших.
- Ограничение на один ответ: выключить для анонимной формы; включить при обязательной авторизации экспертов.
- Уведомление после отправки: "Спасибо за обратную связь. Ваши ответы помогут улучшить платформу и организацию следующих чемпионатов."
